Quick Start

anolisa install tokenless        # install a component
anolisa --json status            # check status (JSON output)
anolisa doctor                   # diagnose issues
anolisa adapter scan             # discover adapters

Agent-Recommended Flags

--json       Machine-readable JSON envelope output
--dry-run    Preview plan without executing
--quiet      Suppress non-error output
--no-color   Disable ANSI color codes
