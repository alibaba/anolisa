Component Architecture

Copilot Shell is the product-level entry point for terminal-native agent workflows. It covers both the current cosh implementation and the newer cosh-ng implementation, while each implementation remains mapped to its source directory.

  • Copilot Shell Terminal-native agent shell and command gateway.
    • cosh: current Copilot Shell implementation in src/copilot-shell/.
    • cosh-ng: next-generation shell implementation in src/cosh-ng/.
  • ANOLISA Runtime Install, inspect, and operate components through the unified CLI.
  • Runtime services SkillFS, workspace checkpoints, Anvil sandbox orchestration.
  • Optimization and memory Tokenless and Agent Memory.
  • Observability AgentSight tracing and dashboard docs.
