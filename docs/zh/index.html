组件架构

Copilot Shell 是终端原生 Agent 工作流的产品级入口，覆盖当前 cosh 实现和新的 cosh-ng 实现；两个实现仍分别映射到各自源码目录。

  • Copilot Shell 终端原生 Agent Shell 与命令网关。
    • cosh：当前 Copilot Shell 实现，源码位于 src/copilot-shell/。
    • cosh-ng：下一代 Shell 实现，源码位于 src/cosh-ng/。
  • ANOLISA Runtime 通过统一 CLI 安装、检查和运维组件。
  • Runtime services SkillFS、工作区快照、Anvil 沙箱编排。
  • Optimization and memory Tokenless 与 Agent Memory。
  • Observability AgentSight 追踪与 Dashboard 文档。
